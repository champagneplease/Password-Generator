# Generador de Contraseñas Aleatorias

Este es un script en Python que genera contraseñas aleatorias con una longitud especificada por el usuario.

## Requisitos

- Python 3.x instalado en el sistema

## Instalación

1. Clona o descarga este repositorio en tu computadora.
2. Asegúrate de tener Python instalado. Puedes verificarlo ejecutando:
   ```sh
   python --version
   ```

## Uso

1. Ejecuta el script en una terminal o línea de comandos:
   ```sh
   python password_generator.py
   ```
2. Ingresa la longitud deseada para la contraseña cuando se solicite.
3. El script generará y mostrará una contraseña aleatoria.

## Ejemplo de ejecución

```
Ingrese la longitud de la contraseña: 12
PASSWORD: f$3gT9&vLmX@
```

## Notas

- El generador usa letras mayúsculas, minúsculas, números y símbolos.
